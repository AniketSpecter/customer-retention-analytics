# Project Submission Guide

## Project author

**Aniket Chakraborty**


## 1. GitHub repository link

Submit:

```text
https://github.com/AniketSpecter/customer-retention-analytics
```

The repository must be public and must contain the `data`, `docs`, `results` and `assets` folders in addition to the source files.

## 2. Research paper link

After uploading this package, open the following file on GitHub and copy its browser URL:

```text
docs/Customer_Retention_Analytics_Research_Report.pdf
```

The URL will use this format:

```text
https://github.com/AniketSpecter/customer-retention-analytics/blob/main/docs/Customer_Retention_Analytics_Research_Report.pdf
```

## 3. Deployed Streamlit link

Deploy the repository on Streamlit Community Cloud using:

```text
Repository: AniketSpecter/customer-retention-analytics
Branch: main
Main file: app.py
```

Submit the final `https://...streamlit.app` URL.

## 4. Project feedback video link

Upload the demonstration video to YouTube as **Unlisted** or **Public**, then submit its `https://youtu.be/...` link. Do not set it to Private.

## Final checks

- All four URLs start with `https://`.
- Repository opens in an incognito window.
- Research PDF opens without permission requests.
- Streamlit app loads and every tab works.
- Video opens without requesting access.
- Only Aniket Chakraborty is shown as the author.
